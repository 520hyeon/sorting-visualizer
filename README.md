# Sorting Visualizer

정렬 알고리즘의 동작을 브라우저에서 한 단계씩 따라가며 볼 수 있는 HTML 프로그램입니다. CLRS(*Introduction to Algorithms*)에 나오는 정렬 알고리즘에, 함께 알아 두면 좋은 알고리즘 몇 가지를 추가했습니다.

## 지원 알고리즘

| 분류 | 알고리즘 |
|---|---|
| CLRS 비교 기반 | Insertion Sort, Merge Sort, Heapsort, Quicksort (Lomuto), Randomized Quicksort |
| CLRS 선형 시간 | Counting Sort, Radix Sort (LSD), Bucket Sort |
| CLRS 연습문제 | Selection Sort, Bubble Sort |
| 추가 알고리즘 | Shell Sort, TimSort (단순화), Introsort, 3-Way Quicksort |

## 주요 기능

- 직접 입력한 리스트, CLRS 예시, 무작위 리스트로 정렬 과정 확인
- 재생, 일시정지, 이전·다음 단계 이동과 속도 조절
- 현재 단계에 해당하는 의사코드 행 강조
- 비교 횟수와 쓰기·교환 횟수 표시
- 같은 값을 구분해 표시하는 안정성 확인 기능
- 라이트/다크 테마

## 실행 방법

`sorting_visualizer.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치는 필요 없습니다.
